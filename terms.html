Terms of Service

Effective date: October 10, 2026

Scope: the Tengo TikTok Sandbox integration test. These terms do not describe all features of the production platform.

1. Test purpose and access

This test is operated by the Tengo integration test team for authorized testers. It validates TikTok OAuth authorization and creator-information API access from a local service. Use only an account you own or are permitted to manage.

2. Your authorization and content

Account access is requested through TikTok's own authorization screen. You decide whether to authorize the requested permissions. The integration requests basic account information and video publishing permission to test API access. The current probe only queries creator information; it does not upload or publish videos. A future publishing test requires a separate explicit instruction identifying the video and posting settings.

3. Appropriate use

Do not use this test to access another person's account without permission, distribute unlawful content, infringe others' rights, or evade TikTok's restrictions. TikTok's applicable terms and policies continue to govern your use of TikTok.

4. Test availability

This is a development test. API access and availability depend on TikTok, app configuration, network conditions, and test software. Errors may occur. No payment or purchase is required by the current local probe.

5. Privacy and ending participation

The Privacy Policy explains the current test's handling of data. You may stop participating and revoke the app's access through TikTok's connected-app settings. Contact the test administrator if you need help.

6. Changes and contact

These pages will be updated before changes to the test's purpose or data handling are introduced. Contact the Tengo integration test administrator who provided your access for service or account questions. Public website corrections can be reported through GitHub issues; do not post credentials or personal data there.
