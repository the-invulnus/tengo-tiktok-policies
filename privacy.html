Privacy Policy

Effective date: October 10, 2026

Scope: the current Tengo TikTok Sandbox integration test, including its local OAuth/API probe. Production use requires a policy reflecting the deployed service's actual data handling.

1. Information processed

When you authorize the test through TikTok, the local backend receives a temporary authorization code and may receive access and refresh tokens, the app-specific account identifier, granted scopes, and expiration metadata. A creator-information request may return your avatar URL, username, nickname, permitted privacy settings, interaction settings, and maximum video duration. The current probe does not upload videos or request your video list.

2. Purpose

These data are used to complete the authorization flow and verify that TikTok permits the creator-information API request. The current test does not use these data for advertising, sell them, or use them to train an AI model.

3. Credentials and storage

Enter your TikTok password only on TikTok's login page. The local probe does not receive your TikTok password. App credentials are kept in a local configuration outside tracked project files. Access tokens and refresh tokens are held only in the running probe's memory and are cleared when that process stops. Creator information is held in the current result in memory and displayed in the local result page.

4. Diagnostics and retention

The probe's application log records the outcome stage, not authorization codes or tokens. The test administrator may keep error messages and screenshots to troubleshoot the integration. Such screenshots can contain visible account information. Contact the administrator to request removal of test diagnostic records. Closing or stopping the probe does not automatically remove screenshots or browser history.

5. Services involved

TikTok processes login, authorization, and API requests under its own policies. This public policy site is hosted by GitHub Pages; GitHub may process website-access data under GitHub's privacy statement. This policy site does not contain account credentials or tokens.

6. Your choices and contact

You can decline authorization, stop the local test, or revoke the application's access through TikTok's connected-app settings. For questions about your data or removal of test diagnostic records, contact the Tengo integration test administrator who provided your access. For public policy-site corrections, use GitHub issues. Do not include personal data, authorization codes, passwords, or tokens in public issues.
